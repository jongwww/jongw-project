# 블랙잭 세션 진행

## 사용자 결과

사용자는 20판을 모두 진행하거나 자금이 0이 될 때까지 배팅이 있는 판을 계속 이어가고, 세션이 끝나면 판별 기록과 결과 요약(총 진행 판 수, 시작 자금, 최종 자금, 순손익)을 확인한다.

## 승인된 범위

- 한 세션은 기존 스펙의 "배팅이 있는 한 판"을 반복해서 진행한다.
- 각 판이 끝날 때마다 판 번호, 배팅액, 결과, 그 판 종료 후 자금을 기록에 남긴다.
- 20번째 판을 마치거나 자금이 0이 되면(둘 중 먼저 도달하는 시점) 세션이 종료된다.
- 세션이 끝나면 판별 기록 전체와 요약(총 진행 판 수, 시작 자금, 최종 자금, 순손익)을 화면에서 확인할 수 있다.
- 세션이 끝난 화면에서 새 세션을 시작할 수 있고, 새 세션은 자금을 초기값으로 되돌리고 기록을 새로 시작한다.
- 세션이 끝나기 전(20판 미만이고 자금이 남아있음)에는 이전 스펙과 동일하게 판이 끝난 뒤 다음 판으로 넘어갈 수 있다.

### 범위 밖 (다음 스펙에서 다룸)

- 더블다운, 인슈어런스, 스플릿: 각각 배팅이 있는 한 판 위에 얹는 별도 규칙으로 개별 스펙에서 다룬다.
- 카드 카운팅, 전략표 힌트: 연습 모드 관련 기능으로 이번 범위 밖이다.
- 판별 기록을 해석해 조언하는 분석성 피드백(예: 실수 패턴 지적, 배팅 전략 평가): 이번 스펙은 기록을 남기고 그대로 보여주는 것까지만 다루고, 기록을 해석하는 것은 다음 스펙에서 다룬다(사용자 확인).
- 기록의 영구 저장: `PRODUCT.md`의 "진행 기록 저장 없음" 경계에 따라 새로고침하면 기록도 함께 사라진다.

## 관찰 가능한 인수 기준

1. 판이 끝나고 다음 판으로 넘어가면, 방금 끝난 판의 번호·배팅액·결과·종료 후 자금이 기록에 추가된다.
2. 20번째 판이 끝나면 자금이 남아있어도 세션이 종료되고, 다음 판으로 넘어가는 대신 세션 종료 화면이 표시된다.
3. 자금이 0이 되면 20판이 되지 않았어도 세션이 종료되고 세션 종료 화면이 표시된다.
4. 세션 종료 화면에는 지금까지 진행한 모든 판의 기록(판 번호, 배팅액, 결과, 그 판 종료 후 자금)이 순서대로 보인다.
5. 세션 종료 화면에는 총 진행 판 수, 시작 자금, 최종 자금, 순손익(최종 자금 − 시작 자금)이 요약으로 표시된다.
6. 세션 종료 화면에서 새 세션을 시작하면, 자금은 초기값으로 돌아가고 기록은 빈 상태가 되어 첫 판의 배팅 화면부터 다시 시작된다.

## 설정 및 근거

- 세션 종료 조건(20판 또는 자금 소진, 둘 중 먼저 도달하는 시점)은 `PRODUCT.md`에서 이미 확정된 경계다.
- 판별 기록은 사용자가 이후 피드백 기능에서 활용하길 원해 이번 스펙에 포함한다(사용자 확인). 다만 기록을 해석해 조언하는 로직은 다음 스펙으로 미룬다.

## 가정

- Assumption: 판별 기록과 세션 상태는 이전 스펙들과 동일하게 브라우저 세션 동안만 유지되고 저장되지 않는다.
- Assumption: 세션 종료 화면에 보이는 기록은 목록(표) 형태로 충분하며, 그래프나 통계 시각화는 이번 범위에 포함하지 않는다.

## 남아있는 위험

- 특별히 확인된 위험 없음.
