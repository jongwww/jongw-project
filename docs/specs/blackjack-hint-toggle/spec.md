# 블랙잭 힌트 토글

## 사용자 결과

사용자는 지금과 같은 하나의 게임 흐름(배팅 → 플레이 → 결과 → 세션 진행)을 그대로 진행하면서, 화면의 도움말(힌트) 토글 하나로 학습 보조 정보(기본 전략표와 추천 행동 하이라이트, 하이-로우 러닝 카운트·트루 카운트, 카운팅 원리 설명)를 즉시 켜거나 끌 수 있다. 별도의 "연습 게임" 진입점이나 화면 전환은 없다.

## 승인된 범위

- 화면에 항상 보이는 도움말(힌트) 토글 하나로 힌트 표시 여부를 즉시 전환한다. 판 중간에 켜고 끄더라도 진행 중인 판, 자금, 세션 진행에는 영향이 없다(순수한 정보 표시 여부만 바뀐다).
- 힌트가 켜져 있을 때, 현재 손의 유형(하드/소프트/페어)과 딜러 오픈 카드 조합에 해당하는 기본 전략표 전체가 화면에 표시되고, 현재 상황에 해당하는 칸이 하이라이트된다.
- 힌트가 켜져 있을 때, 현재 정답 행동(히트/스탠드/더블다운/스플릿)에 해당하는 액션 버튼이 함께 강조 표시된다. 인슈어런스 제안 화면에서는 "인슈어런스 거절"이 정답으로 강조된다(기본 전략표의 표준 권고를 따르며, 카운트 기반 예외는 다루지 않는다).
- 힌트가 켜져 있을 때, 하이-로우 방식의 러닝 카운트와 남은 덱 수를 반영한 트루 카운트가 실시간으로 표시된다.
- 힌트가 켜져 있을 때, 카드 카운팅의 원리(러닝 카운트 계산법, 트루 카운트 계산법)를 설명하는 도움말을 전략표와는 별도로 확인할 수 있다.
- 힌트가 꺼져 있으면 전략표, 하이라이트, 카운트 표시, 카운팅 설명 도움말이 모두 화면에서 사라지고, 지금과 동일한 화면(카드·배팅·액션 버튼만)만 보인다.
- 러닝·트루 카운트가 여러 판에 걸쳐 의미를 가지도록, 세션 시작 시 여러 벌(6덱)을 섞은 슈 하나를 만들어 판이 바뀌어도 이어서 사용하고, 슈의 소진 비율이 일정 수준(전체의 75%)을 넘어서면 다음 판이 시작되기 전에 슈를 다시 섞는다. 기존의 "판마다 새 52장 한 벌" 방식은 이 스펙에서 슈 방식으로 대체된다.
- 카운트는 힌트가 꺼져 있는 동안에도 내부적으로 계속 누적되어, 다시 켰을 때 실제 슈 상태와 일치하는 값을 보여준다. 사용자가 껐다 켠다고 카운트가 리셋되지 않는다.
- 새 세션을 시작하면 슈도 새로 섞이고 카운트도 0부터 다시 시작한다.

### 범위 밖 (다음 스펙에서 다루거나 이번 범위 아님)

- 카운트에 따라 배팅액을 조정하도록 유도하거나 강제하는 기능(예: 카운트 기반 배팅 추천): 이번 스펙은 정보 표시까지만 다루고 배팅 전략 코칭은 다루지 않는다.
- 인슈어런스의 카운트 기반 예외 전략(트루 카운트가 특정 값 이상일 때 인슈어런스가 유리하다는 고급 전략): 기본 전략표 수준의 안내만 다룬다.
- 세션 종료 후 피드백 화면에 카운팅·전략 성과를 반영하는 것(예: "정답률", "카운트 활용도"): `blackjack-session` 스펙에서 이미 범위 밖으로 다룬 분석성 피드백의 연장이며, 이번 스펙에도 포함하지 않는다.
- 덱 수, 페네트레이션 비율 등 하우스 룰 변형을 사용자가 직접 설정하는 기능: 고정값을 사용한다.

## 관찰 가능한 인수 기준

1. 게임 화면 어디서든 도움말(힌트) 토글을 켜면, 현재 손 상황에 맞는 기본 전략표 전체와 하이라이트된 칸, 정답 행동이 강조된 버튼, 러닝 카운트, 트루 카운트가 함께 나타난다.
2. 힌트를 끄면 전략표, 하이라이트, 카운트 표시, 카운팅 설명 도움말이 모두 사라지고 카드·배팅·결과·액션 버튼만 남은, 지금과 같은 화면이 된다.
3. 힌트를 켜고 끄는 동작 자체는 진행 중인 판의 카드, 자금, 배팅액, 세션의 판 번호에 아무 영향을 주지 않는다.
4. 새 카드가 한 장 보일 때마다(플레이어 히트, 딜러 카드 공개 등) 러닝 카운트가 하이-로우 값(2~6: +1, 7~9: 0, 10/J/Q/K/A: -1)만큼 즉시 갱신된다.
5. 트루 카운트는 "러닝 카운트 ÷ 슈에 남은 덱 수"로 계산되어 러닝 카운트와 함께 갱신된다.
6. 스플릿이 발생하면, 화면에서 진행 중으로 표시된 손을 기준으로 전략표 하이라이트와 추천 행동이 그 손의 카드 구성에 맞게 갱신된다.
7. 한 세션 안에서 여러 판을 진행해도 슈가 유지되어, 이전 판에서 나온 카드로 계산된 러닝·트루 카운트가 다음 판 시작 시 리셋되지 않고 이어진다.
8. 슈의 남은 카드 비율이 25% 미만이 되면, 그 판이 끝난 뒤 다음 판이 시작되기 전에 슈가 새로 섞이고 러닝·트루 카운트가 0으로 초기화된다.
9. 새 세션을 시작하면 슈가 새로 섞이고 러닝 카운트와 트루 카운트가 0으로 초기화된 상태에서 첫 판이 시작된다.
10. 힌트를 끈 상태로 몇 판을 진행한 뒤 다시 켜면, 그동안 쌓인 카운트가 반영된 값이 즉시 보인다(꺼진 동안에도 카운트 계산이 멈추지 않았음을 확인할 수 있다).

## 설정 및 근거

- 별도의 "연습 게임"과 "본 게임" 화면 전환을 없애고, 하나의 게임 흐름 위에서 힌트 토글로 학습 보조 정보 표시 여부만 바꾸는 방식으로 확정한다(사용자 확인). `PRODUCT.md`의 Core loop·Capabilities·Experience principles는 이 결정에 맞춰 이미 갱신했다.
- 힌트가 켜져 있어도 실제 판정 규칙, 배팅액, 자금 결과는 지금과 동일하게 적용된다. 힌트는 순수한 정보 제공이며, 판을 쉽게 만들거나 결과를 바꾸지 않는다.
- 러닝·트루 카운트가 실제로 의미를 가지려면 여러 판에 걸쳐 카드가 소진되는 슈가 필요하다는 점을 확인하고, 기존의 "판마다 새 52장 한 벌" 방식을 세션 동안 유지되는 슈 방식으로 바꾸기로 확정했다(사용자 확인). 이는 `blackjack-single-hand` 스펙의 기존 가정("카드 카운팅이 범위에 없어 덱 소진을 다루지 않는다")이 카운팅이 범위에 들어오면서 재검토된 결과이며, `PRODUCT.md`가 이미 가정한 "멀티덱 슈"와도 일치한다.
- 인슈어런스 힌트는 카운트 기반 고급 전략이 아니라 기본 전략표 수준의 고정된 권고("거절")로 단순화한다. 고급 카운트 기반 인슈어런스 전략은 이번 스펙의 목표(도움말 토글 전환)를 넘어서는 별도 학습 주제로 판단했다.

## 가정

- Assumption: 슈는 6덱(312장)을 사용하고, 남은 카드가 전체의 25% 미만이 되면 다음 판 시작 전에 다시 섞는다. 실제 카지노에서도 덱 수와 페네트레이션 비율은 매장마다 다르므로, 학습 목적에 흔히 쓰이는 값으로 추정했다.
- Assumption: 힌트 토글의 세션 시작 시 기본값은 켜짐(ON)이다. 학습이 목적인 게임이므로, 처음 화면을 여는 사용자가 바로 도움을 받을 수 있도록 기본으로 켜둔다.
- Assumption: 트루 카운트는 "남은 카드 수 ÷ 52"로 남은 덱 수를 구하고, 소수 첫째 자리까지 반올림한 값으로 러닝 카운트를 나눈 값으로 표시한다.
- Assumption: 카운팅 원리를 설명하는 도움말은 전략표·카운트 표시와는 별개의 펼침 영역으로 제공되며, 항상 펼쳐진 상태로 강제하지 않는다.
- Assumption: 힌트 토글 상태 자체는 저장되지 않고, 페이지를 새로고침하면 다시 기본값(켜짐)으로 돌아간다. `PRODUCT.md`의 "진행 기록 저장 없음" 경계를 그대로 따른다.

## 남아있는 위험

- 슈 방식으로의 전환은 `lib/blackjack/deck.ts`와 `lib/blackjack/session.ts`가 다루던 "판마다 새 덱"이라는 기존 전제를 바꾸는 것이라, 관련 기존 테스트의 가정도 함께 재검토가 필요할 수 있다.
