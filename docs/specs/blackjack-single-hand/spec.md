# 블랙잭 한 판 플레이

## 사용자 결과

사용자는 웹 화면에서 딜러를 상대로 블랙잭 한 판을 실제로 진행한다. 카드를 배분받고, 히트 또는 스탠드를 선택하고, 딜러 턴을 거쳐 승/무/패/블랙잭 승 중 하나의 결과를 눈으로 확인한다.

## 승인된 범위

- 새 판 시작: 플레이어에게 카드 2장, 딜러에게 카드 2장을 배분한다. 딜러 카드 중 한 장은 플레이어 턴 동안 가려진 상태로 표시된다.
- 처음 받은 두 장의 합이 21(블랙잭)인 경우, 히트/스탠드 선택 없이 즉시 결과를 판정한다.
- 플레이어는 히트(카드 한 장 추가) 또는 스탠드(턴 종료) 중 하나를 선택할 수 있다.
- 플레이어가 21을 초과하면 즉시 버스트로 패 처리하고, 딜러 턴은 진행하지 않는다.
- 플레이어가 스탠드하면 딜러의 가려진 카드를 공개하고, 딜러는 표준 규칙(합계가 17 미만이면 히트, 소프트 17을 포함해 17 이상이면 스탠드)에 따라 카드를 받는다.
- 딜러 턴 종료 후 승/무/패/블랙잭 승을 판정하고 화면에 표시한다.
- 결과 확인 후 새 판을 다시 시작할 수 있다.

### 범위 밖 (다음 스펙에서 다룸)

- 더블다운, 스플릿, 인슈어런스: 배팅 금액 조정과 카드 분할이라는 별도 규칙이 필요해 이번 "한 판이 실제로 돌아가는지" 검증 범위를 넘어선다.
- 배팅 금액·칩 관리: 이번 판정은 승/무/패/블랙잭 승 여부만 다루고 금액 계산은 하지 않는다.
- 여러 판으로 이어지는 세션 진행과 세션 종료 후 피드백.
- 연습 모드의 전략표 힌트, 카드 카운팅(러닝 카운트·트루 카운트) 표시.
- 회원가입·로그인, 진행 기록 저장 (`PRODUCT.md`에서 이미 전역적으로 제외됨).

## 관찰 가능한 인수 기준

1. 새 판을 시작하면 플레이어 카드 2장이 모두 보이고, 딜러 카드 2장 중 한 장은 가려진 채로 표시된다.
2. 플레이어와 딜러가 받은 첫 두 장의 합이 21이면, 히트/스탠드 선택지 없이 즉시 결과가 판정되어 표시된다: 플레이어만 21이면 "블랙잭 승", 양쪽 모두 21이면 "무승부", 딜러만 21이면 "패".
3. "히트"를 선택하면 카드 한 장이 추가로 표시되고, 합계가 21을 초과하면 즉시 "패(버스트)"로 결과가 표시되며 딜러 카드는 그대로 가려진 상태를 유지하지 않고 공개된다.
4. "스탠드"를 선택하면 딜러의 가려진 카드가 공개되고, 딜러 합계가 17 미만인 동안 카드가 계속 추가되는 과정이 화면에 나타난다.
5. 딜러가 21을 초과하면 "승"이 표시된다.
6. 플레이어와 딜러 모두 21 이하로 멈추면, 합계가 더 높은 쪽이 "승"/"패"로 표시되고 합계가 같으면 "무승부"로 표시된다.
7. 결과가 표시된 화면에서 새 판을 다시 시작할 수 있는 수단이 있고, 이를 선택하면 새로운 카드 배분부터 다시 시작된다.

## 설정 및 근거

- 딜러 행동 규칙(소프트 17 히트 포함, 17 이상 스탠드)은 `PRODUCT.md`의 표준 카지노 규칙 가정을 그대로 따른다.
- 플레이어 행동은 히트/스탠드로 제한한다. 더블다운·스플릿·인슈어런스는 배팅 조정이나 카드 분할 같은 별도 규칙을 동반해 범위를 키우므로 다음 스펙으로 미룬다(사용자 확인).

## 가정

- 매 판마다 새로 섞은 단일 카드 한 벌(52장)을 사용한다. 카드 카운팅이 이번 범위에 없어 덱 소진이나 여러 판에 걸친 카드 연속성은 다루지 않는다.
- 딜러 카드 한 장을 가리고 플레이어 턴 동안 유지했다가 딜러 턴에 공개하는 방식은 실제 카지노 관행을 따른 것으로, 별도 확인 없이 채택한다.
